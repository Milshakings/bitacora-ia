Bitácora IA: Captura Inteligente v3

Aplicación web desarrollada en Next.js (App Router) y Tailwind CSS para registrar eventos, seminarios y reuniones con fotos, geolocalización real e integración con motores de búsqueda profesionales.

🚀 Pasos para ejecutar localmente

1. Crear la carpeta e instalar dependencias

Abre tu terminal y ejecuta:

# Crear la carpeta del proyecto
mkdir bitacora-ia
cd bitacora-ia

# Generar los archivos según la estructura indicada abajo
# Luego instalar las dependencias:
npm install


Estructura de archivos del proyecto:

bitacora-ia/
├── app/
│   ├── globals.css
│   └── page.jsx
├── .gitignore
├── package.json
├── postcss.config.js
├── tailwind.config.js
└── README.md


2. Probar en entorno de desarrollo

npm run dev


Abre http://localhost:3000 en tu navegador para ver la aplicación funcionando.
